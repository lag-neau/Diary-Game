# 지워지는 일기장

매일 밤 일기 한 줄을 지워야 다음 날이 오는, 이야기 중심의 짧은 웹 게임입니다.
지운 일은 다음 날 세상에서 없던 일이 됩니다. 무엇을 남길지가 곧 결말입니다.

- 상태: 버전 0.1 (1일째까지 플레이 가능)
- 플레이: https://lag-neau.github.io/Diary-Game/ (GitHub Pages를 켜면 열려요)
- 폰·컴퓨터 브라우저에서 설치 없이 바로

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `index.html` | 게임 시작 파일 |
| `story/` | 대본 (날마다 한 파일). 쓰는 법은 `docs/05-대본-쓰는-법.md` |
| `src/` | 게임 엔진: 장면 그림(`art.js`), 화면(`stage.js`), 대본 읽기(`script.js`), 일기장(`diary.js`), 저장(`save.js`), 진행(`main.js`) |
| `styles/` | 색과 모양 |
| `docs/` | 기획서, 결정 기록, 변경 기록, 인물과 엔딩, 대본 쓰는 법, 시안 |
| `qa/` | 자동 플레이 점검 스크립트 |

## 컴퓨터에서 직접 돌려 보기

```
python3 -m http.server 8000
```
그리고 브라우저에서 `http://localhost:8000` 을 엽니다. (파일을 더블클릭해서 열면 대본을 못 읽어요.)
