# 대본 쓰는 법

대본은 `story/` 폴더의 글 파일입니다. 예: `story/day1.txt`
메모장이나 GitHub 웹에서 바로 고칠 수 있어요. 고친 뒤 저장하면 게임에 그대로 반영됩니다.

## 기본

| 쓰는 모양 | 뜻 |
| --- | --- |
| `# 아무 글` | 메모. 게임에 안 나와요 |
| `== 이름 ==` | 장면의 이름표. 선택지나 이동이 여기로 옵니다 |
| `역장: 종점이다.` | 인물 대사 (이름: 대사) |
| `@글 눈을 떠 보니…` | 해설 (이름 없이 나오는 글) |

## 선택지

```
* 아직이요 -> 밥 {배고픔}
* 먹었어요 -> 거짓말 {거짓말}
```

- `->` 뒤는 갈 곳(이름표), `{ }` 안은 고르면 켜지는 **깃발**입니다. 깃발은 없어도 돼요.
- 줄이 붙어 있으면 한 번에 고르는 선택지가 됩니다.

## 명령

| 명령 | 뜻 |
| --- | --- |
| `@장면 승강장 저녁 할머니 역장` | 장면 바꾸기: 장소, 시간, 나오는 사람 |
| `@이동 이름` | 그 이름표로 건너뛰기 |
| `@만약 깃발 -> 이름` | 깃발이 켜져 있으면 건너뛰기 (`!깃발`은 꺼져 있으면) |
| `@깃발 이름` | 깃발 켜기 |
| `@비 켜기` / `@비 끄기` | 비 내리기 |
| `@흔들림` | 화면 흔들기 |
| `@쉬기 1` | 1초 쉬기 |
| `@날 2` | 날짜 바꾸기 |
| `@일기 태풍` | 일기장 열기 (뒤의 말은 날씨 칸) |
| `@아침결과` | 지운 줄의 "다음 날 아침" 글 보여 주기 |
| `@끝` | 이번 판 끝 |

- 장소: `기차`, `승강장`, `마당`, `부엌`, `방`, `검정`
- 시간: `낮`, `아침`, `저녁`, `밤`, `어스름`(어두운 방), `불빛`(전등 켠 방)
- 사람: `역장`, `할머니`, `아저씨` (주인공은 늘 나와요)

## 일기 줄

```
@일기줄 아이디 | 조건 | 일기 문장 | 지운 다음 날 아침
```

- 조건: `항상`, `깃발`, `!깃발`
- 지운 다음 날 아침 글을 `//`로 나누면 여러 번에 나눠 보여 줘요.
- 마지막 칸에 `고정`이라고 쓰면 지울 수 없는 줄이 됩니다.
- 하룻밤 일기는 조건에 맞는 줄이 5개가 되도록 맞춰 주세요.

## 틀렸을 때

없는 이름표로 가려 하거나 모양이 틀리면, 게임 화면에 "대본 오류 · 몇 번째 줄"이 떠요. 그 줄을 고치면 됩니다.
